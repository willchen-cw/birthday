# 猫猫生日筹备委员会

一个适配手机竖屏的生日网页小游戏。所有插画均由本地 SVG 绘制，不需要照片、外部图片、字体服务或后端。

## 本地运行

```sh
npm install
npm run dev
```

在电脑访问终端显示的地址。手机与电脑连接同一个 Wi-Fi 后，访问终端显示的 Network 地址。Windows 如提示防火墙，请允许本地网络访问。

## 构建与分享

```sh
npm run build
npm run preview
```

将生成的 `dist` 目录上传到支持静态网站的托管平台即可通过链接分享。微信内打开需要托管网址在当地网络可访问。Vite 使用相对资源路径，也支持部署到子目录。

### GitHub Pages

网站地址：<https://willchen-cw.github.io/birthday/>

仓库的 `Settings → Pages → Source` 选择 `GitHub Actions`。推送到 `main` 后，`.github/workflows/deploy.yml` 会安装依赖、构建并自动发布。也可以在仓库 Actions 页面手动运行 `Deploy GitHub Pages`。发布进度见 <https://github.com/willchen-cw/birthday/actions>。

## 互动

- 点击「推门，抓个现行」入场；三个任务可以自由选择顺序。
- 任务会把同一个房间平滑放大到对应区域，完成后拉回全景。手机上使用整屏近景，桌面上使用场景与道具并排布局。
- 奶盖：拖动闹钟、主持词到纸箱旁；滑开猫条包装，再拖到鼻子前。也可点按道具与投喂按钮。醒来的奶盖会跳出纸箱，跑到舞台。
- 蛋糕：拖动装饰到蛋糕上，或先点选装饰再点落点。至少放三份；实际摆放位置会保存到房间和生日卡。金币伸爪时，直接拍爪子拦住它。
- 舞台：拖动横幅右端扶正，镜头随即推近礼炮；向下拉绳子试放，再拉回舞台看效果。灯光选择立即改变整间房间。横幅、礼炮也有点按操作。
- 完成后庆典依次拍主持人、蛋糕、全景，再推近蜡烛进入许愿。可略过开场，或退出后继续许愿。
- 生日卡在本地生成 PNG，支持预览、下载与移动端系统分享（浏览器支持时）。
- 顶栏可编辑寿星昵称、开启或关闭合成音乐。默认静音。
- 昵称、任务进度与舞台选择保存在当前浏览器，可通过页脚「重新开会」重置。
- 支持键盘操作、减少动态效果设置以及手机安全区域。

## 定制

首页、存档、音乐与生日卡在 `src/main.js`；房间插画和可更新的场景层在 `src/art.js`；镜头、拖动与任务流程在 `src/scene.js`；首页样式在 `src/styles.css`，沉浸场景样式在 `src/scene.css`。旧版装饰存档会兼容读取。
